# 🚀 Proyek Machine Learning - Clustering & Classification

## 📌 Deskripsi Proyek
Proyek ini merupakan implementasi teknik Machine Learning yang mencakup dua pendekatan utama:
- Clustering (Unsupervised Learning)
- Classification (Supervised Learning)

Tujuan proyek:
- Mengelompokkan data berdasarkan pola tertentu
- Membangun model prediksi menggunakan klasifikasi
- Mengevaluasi performa model untuk mendapatkan hasil terbaik

## 📊 Penjelasan Proyek

### 1. Clustering
Tahapan yang dilakukan:
- Data preprocessing
- Dimensionality reduction menggunakan PCA
- Penerapan algoritma clustering
- Analisis hasil clustering

File terkait:
- customer_segmentation_clustering.ipynb
- model_clustering.h5
- PCA_model_clustering.h5

---

### 2. Classification
Tahapan yang dilakukan:
- Exploratory Data Analysis (EDA)
- Training model:
  - Decision Tree
  - Random Forest
- Hyperparameter tuning
- Evaluasi model

File terkait:
- transaction_classification_model.ipynb
- decision_tree_model.h5
- explore_random_forest_classification.h5
- tuning_classification.h5
